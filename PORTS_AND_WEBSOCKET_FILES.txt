## WebSocket Event Flow

```
1. Frontend connects to ws://localhost:5000 (Socket.IO)
   ↓ App.py initializes socketio
   
2. Backend receives 'connect' event
   ↓ websocket.py → handle_connect()
   ↓ Emits 'connected' back to client
   
3. Frontend calls Generation API (HTTP POST /api/generate)
   ↓ Backend returns generation_id
   
4. Frontend gets generation_id, emits 'join_generation' to WebSocket
   ↓ websocket.py → on_join(data)
   ↓ Joins client to room: generation_{id}
   
5. Backend processes generation in background thread
   ↓ When complete, emits to room: generation_{id}
   ↓ socketio.emit('generation_update', {...}, room=f'generation_{id}')
   
6. Frontend receives 'generation_update' event
   ↓ useGenerationStatus hook → state updated
   ↓ Image URL set → Image displays ✅
```

## Inference Steps Fix

**Issue**: Config changed from 25→15 but backend still using 25

**Root Cause**: Old backend process has cached config

**Solution**:
1. Kill old process: `taskkill /pid <PID> /f`
2. Clear cache: `Get-ChildItem -Recurse -Filter __pycache__ | Remove-Item -Recurse -Force`
3. Restart: `python app.py`

**Backend now accepts steps from frontend**:
- Frontend sends: `num_inference_steps: 15` in request
- Backend uses frontend value OR falls back to config (DEFAULT_STEPS)
- File: `generation.py` line 74 & 155
